# Три жизни

Личный планер для студентки, которая работает и встречается: учёба, работа и отношения в одном месте. Работает как Telegram Mini App и как обычная страница на GitHub Pages.

## Разделы

- **Планер**: неделя с балансом времени по сферам и целями в часах, нагрузка по дням, предупреждение о перегруженных днях, свободные окна в расписании с подсказкой, какой шаг дедлайна туда поставить. Рабочий график и пары с повтором каждую неделю.
- **Дедлайны**: шаги с оценкой времени, расчёт «когда пора начинать», шкала на три недели, поиск дней, где сходятся две сдачи.
- **Учёба**: предметы сессии, условия допуска (галочки, счётчики вроде лабораторных, посещаемость), автоматы и рейтинг до автомата, перенос недостающего в дедлайны.
- **Бюджет**: сколько можно тратить в день до конца месяца, траты по категориям и в часах работы, цель с планом накоплений, общие траты с партнёром.
- **Приветствие**: пять коротких шагов настройки и пример с готовыми данными.

## Как устроено

Статические файлы без сборки: `index.html`, `style.css`, `app.js`. Данные пока хранятся в `localStorage` на устройстве, в настройках есть выгрузка и загрузка копии.

## Дальше

1. Свой бот в Telegram (@BotFather) и вход через Telegram.
2. Хранение данных в базе Supabase проекта Duo, общие события и траты с партнёром из Duo.
3. Сообщения бота: утренняя сводка, «была на паре?», «пора начинать», итог недели, быстрый ввод («кофе 350», «эссе до 6.11»).
4. Импорт расписания пар и рабочего календаря.
